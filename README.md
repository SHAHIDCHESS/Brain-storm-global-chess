# Brain Storm Global Chess Academy Website

Premium responsive frontend website created for Brain Storm Global Chess Academy.

## Files
- `index.html` — complete website and all sections
- `styles.css` — responsive premium design
- `script.js` — navigation, animations, forms and portal demo
- `assets/logo.png` — supplied academy logo

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy
This static site can be deployed on GitHub Pages, Netlify, Vercel or any normal web host.

## Before production
Replace:
- WhatsApp number
- email
- location / Google Maps embed
- social links
- coach information
- real achievements
- real testimonials
- blog content

The Student / Coach / Admin portals are currently frontend demo interfaces. Production authentication, database, payments and dashboards require a backend.
